# 台湾旅行ガイド

台湾旅行用の静的ガイドです。2026年10月の台北・台中・台南を回る案について、旅行中に必要なルート、都市の違い、支払い、移動、公式リンクを1ページにまとめています。

公開先: https://yugo969.github.io/taiwan-travel-guide-site/

## Files

- `index.html`: ガイド本文と公式リンク
- `styles.css`: デスクトップ・モバイルのレイアウト
- `app.js`: ページ内メニュー、モバイル用ショートカット、台北・台中・台南の現在天気表示

## Purpose

旅程ページに準備タスクを並べず、固定ナビの「準備」から2つの表示を開きます。モーダル上部は「準備ボード」「出発前チェック」と閉じる操作に絞り、その下の表示領域を広く使います。「準備ボード」は通常版のタスクスケジュールを台湾旅行グループに絞って、進捗共有のまま明るい台湾配色で表示します。「出発前チェック」は携行品・入国手続き・現地調達をまとめます。チェック状態はこの端末に保存します。天気はOpen-Meteoの公開APIから取得し、状態アイコンはLucideを使います。警報・台風はCWA公式ページで確認します。
