# 台湾旅行ガイド

台湾旅行用の静的ガイドです。実際の日程、台中の食事候補、都市の比較、旅の気づきまとめ、交通・支払い、コンビニでの注文、YouBike、虫よけ・虫刺され対応、公式リンクを1ページにまとめています。食事・日程・交通の詳細は折りたたみ式です。食事グループは時間帯をLucideアイコンで示し、開いたときだけ地図リンクを表示します。トップの「気づきまとめ」から課題と対策・次回の考えをダイアログで確認できます。店ごとの小さな写真は掲載元サイトの画像を直接参照し、リポジトリには保存しません。写真をクリック／タップすると、元画像をトリミングせずモーダルで拡大表示できます。

都市比較はPCでは3都市を並べ、スマートフォンでは台北・台中・台南のタブで1都市ずつ表示します。JavaScriptが使えない場合は3都市を縦に表示します。

日程欄には10月16日〜21日の実際の宿泊地と移動を記載しています。PCでは天気を日程から分けて左側に表示し、スマートフォンでは日程の後に表示します。10月18日午後の旧市街案、帰国当日の西門から桃園空港への移動、食事の候補は折りたたんで表示します。上海未名麵點酸梅湯と第二市場は昼の候補です。

店名・注文文など、現地で声に出して使う中国語は繁体字と標準中国語のピンインを並記します。地図検索に使う原文は残し、日本語の意味も近くに置きます。

公開先: https://yugo969.github.io/taiwan-travel-guide-site/

スマートフォンでは上部にサイト名を残し、主要セクションと「準備」は画面下のナビゲーションにまとめます。

## Files

- `index.html`: ガイド本文と公式リンク
- `styles.css`: デスクトップ・モバイルのレイアウト
- `app.js`: ページ内メニュー、気づきダイアログ、準備ビュー切替、出発前チェック、台北・台中・台南の現在天気表示

## Purpose

旅程ページに準備タスクを並べず、固定ナビの「準備」から全画面の準備ビューへ切り替えます。「準備ボード」と「出発前チェック」を切り替え、ガイドへ戻ると元のスクロール位置へ復帰します。準備中は共通ナビを隠し、戻る操作は切替ナビ内に1つだけ表示します。各タブのスクロール領域は画面幅いっぱいにし、チェック内容だけを中央の読みやすい幅に保ちます。出発前チェックのスクロールバーは画面右端に置きます。「準備ボード」は通常版のタスクスケジュールを台湾旅行グループに絞って、進捗共有のまま明るい台湾配色で表示します。台湾用表示では時間割タブを出さず、モバイルの追従見出しとスクロールバーも明るい配色にします。「出発前チェック」は携行品・入国手続き・現地調達をまとめます。チェック状態はこの端末に保存します。天気はOpen-Meteoの公開APIから取得し、状態アイコンはLucideを使います。警報・台風はCWA公式ページで確認します。
