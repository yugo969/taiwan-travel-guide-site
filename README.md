# 台湾旅行ガイド

台湾旅行用の静的ガイドです。2026年10月の台北・台中・台南を回る案について、旅行中に必要なルート、都市の違い、支払い、移動、公式リンクを1ページにまとめています。

公開先: https://yugo969.github.io/taiwan-travel-guide-site/

## Files

- `index.html`: ガイド本文と公式リンク
- `styles.css`: デスクトップ・モバイルのレイアウト
- `app.js`: ページ内メニュー、モバイル用ショートカット、台北・台中・台南の現在天気表示

## Purpose

このページは準備タスクを並べる場所ではありません。最初に決めることと3都市の現在天気を短く示し、詳細は「ルート」「都市」「移動と支払い」「現地メモ」に分けています。天気はOpen-Meteoの公開APIから取得し、状態アイコンはLucideを使います。警報・台風はCWA公式ページで確認します。

## Next steps

1. 航空券や宿が決まったら、`index.html` の帰国・入国・泊数表記を更新します。
2. 追加したい場所は、都市欄または現地メモに短く足し、地図リンクを添えます。
3. 公開前にデスクトップとモバイルを確認します。
